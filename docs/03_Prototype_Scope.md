## 1. Prototype Description
The RoomLight prototype will be a digital demonstration designed for hotel owners and technical managers (and vice presidents) to prove the value in the concept of "Configure Once, Sync Everywhere". The main feature is the virtual central dashboard where staff can define lighting templates for different room types (e.g., "Standard" vs "Suite") and a virtual room interface that mimics the simplified control panel in each room. The prototype proves that a non-technical member of staff can adjust the lighting across hundreds of rooms in minutes and verify room statuses remotely. It also demonstrates the frictionless experience for the guest.


## 2. Demonstrate
The prototype is designed to prove the following requirements from the product backlog:

| REQ-ID | Why this is included in the prototype? |
| :--- | :--- |
| **REQ-01** | **Guest Intuition:** The prototype will show configurable plain language labels on the guest panel. This provev the systems ability make sure guests no longer have to guess which switch controls which light. |
| **REQ-03** | **Staff Configuration:** By allowing a staff member to create a "Suite" template vs a "Standard" template, we prove the system handles various room layouts as requested by the VP. |
| **REQ-04** | **Scalability:** The prototype will include a "Sync to Floor" button to demonstrate how 200 rooms can be updated instantly, answering the VP's question on time-saving. |
| **REQ-06** | **Operational Efficiency:** We will demonstrate a timer triggering "Checkout" event that clears all lights in a specific room, proving the system reduces electricity expenses and manual labor. |
| **REQ-07** | **Remote Management:** The dashboard will show a "Pre-arrival" toggle and a timer, allowing the Night Manager to prepare rooms for a conference group without physically visiting them. |
